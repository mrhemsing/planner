# Princess Planner

Princess Planner is the starting point for a meal-planning app centered on 5-day planning blocks.

## Current v1 slice

- 5-day meal plan overview
- Quick-glance recipe cards
- Wild Rose recipe source links
- Ingredient-based shopping list
- Check-off grocery items in the UI

## Current recipe source

Recipes are currently modeled from Wild Rose recipe pages:
- https://wildrose.ca/blogs/recipes

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000
